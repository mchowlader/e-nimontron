# 🪷 শুভ বিবাহ ই-নিমন্ত্রণপত্র (Hindu Wedding Digital Invitation)

একটি আধুনিক, মার্জিত এবং রাজকীয় সনাতন হিন্দু বিবাহ ডিজিটাল নিমন্ত্রণপত্র (E-Nimontron) প্ল্যাটফর্ম। এটি সম্পূর্ণ বিনামূল্যে **GitHub Pages** অথবা **Vercel**-এ আজীবনের জন্য $0 খরচে হোস্ট করা যায়।

---

## 🌟 মূল বৈচিত্র্য ও সুবিধাসমূহ (Key Features)

1. **পবিত্র বৈদিক ও সংস্কৃত আবহ:**
   * **ॐ শ্রী গণেশায় নমঃ** সহ খাঁটি দেবনাগরী ও বাংলা মাঙ্গলিক শ্লোক।
   * সাতপাকের বৈদিক শ্লোক (*"যদেতদ্ধৃদয়ং তব তদেতদ্ধৃদয়ং মম..."*) এবং সপ্তপদীর সাতটি প্রতিশ্রুতির সুন্দর ব্যাখ্যা।
2. **চলচ্চিত্রের জনপ্রিয় সংস্কৃত বিবাহ সঙ্গীত (Movie Song Selection):**
   * এ. আর. রহমানের বিখ্যাত ও জনপ্রিয় চলচ্চিত্র সংগীত: **"মাঙ্গল্যং তন্তুনানেন" (Saathiya)** — যাতে মূল বৈদিক বিবাহের মাঙ্গলিক সূত্রবন্ধনের সংস্কৃত শ্লোক রয়েছে।
   * ঐতিহ্যবাহী মঙ্গল সানাই ও বাঁশির মাঙ্গলিক ধুন (Traditional Shehnai Mangal Dhun)।
   * ফ্লোটিং প্লেয়ার, ভলিউম কন্ট্রোল এবং মিউট টগল।
3. **দ্বিভাষিক সুবিধা (Bilingual Toggle):**
   * এক ক্লিকে **বাংলা** এবং **English**-এর মধ্যে সম্পূর্ণ সাইট রূপান্তর।
4. **ডিজিটাল খাম উন্মোচন অ্যানিমেশন (Interactive Wax-Seal Envelope):**
   * প্রথমবার সাইটে প্রবেশ করলে একটি রাজকীয় সিলমোহরযুক্ত ডিজিটাল খাম আসে। ট্যাপ করলেই গোল্ডেন কনফেটি বিস্ফোরণ সহ খাম খুলে নিমন্ত্রণপত্রটি উন্মোচিত হয়।
5. **ঝরে পড়া ফুলের পাপড়ি (Falling Petals Canvas):**
   * স্ক্রিনে আলতো করে গাঁদা ও গোলাপের পাপড়ি পড়ার মিষ্টি ইফেক্ট (চালু/বন্ধ করার বোতাম সহ)।
6. **লাইভ কাউন্টডাউন টাইমার (Live Countdown):**
   * শুভ লগ্ন পর্যন্ত দিন, ঘণ্টা, মিনিট ও সেকেন্ডের রিয়েলটাইম কাউন্টডাউন।
7. **বর ও কনে এবং উভয় পক্ষের পিতা-মাতার নাম:**
   * বর ও কনের সুন্দর পোর্ট্রেট ফ্রেম এবং উভয় পরিবারের পিতা-মাতার সশ্রদ্ধ নাম ও আশীর্বাদবাণী।
8. **সম্পূর্ণ অনুষ্ঠানসূচি ও সময়:**
   * গায়ে হলুদ ও সঙ্গীত, শুভ বিবাহ অনুষ্ঠান ও সপ্তপদী, এবং প্রীতিভোজ ও বৌভাত সংবর্ধনা।
   * **Google Calendar**-এ ১-ক্লিকে যুক্ত করার সুবিধা।
   * **Apple / Outlook Calendar (.ics)** ফাইল ডাউনলোড।
9. **গুগল ম্যাপ ভেন্যু ইন্টিগ্রেশন:**
   * শ্রী শ্রী ঢাকেশ্বরী জাতীয় মন্দির প্রাঙ্গণসহ সকল ভেন্যুর গুগল ম্যাপ এমবেড এবং লাইভ ড্রাইভিং দিকনির্দেশনা (GPS Navigation)।
10. **ইন্টারেক্টিভ RSVP ব্যবস্থা (কে আসবে কে আসবে না):**
    * মেহমানদের নাম, মোবাইল নম্বর, উপস্থিতি স্ট্যাটাস (আনন্দসহকারে উপস্থিত থাকব / আসতে পারব না), মেহমান সংখ্যা (১-১০ জন) এবং খাবার সংক্রান্ত অনুরোধ।
    * সরাসরি ব্রাউজারে সংরক্ষিত থাকে এবং সাথে সাথে বরের/কনের পরিবারের **WhatsApp**-এ কনফার্মেশন পাঠানোর লিংক তৈরি করে।
11. **ছবিসহ শুভেচ্ছা ও আশীর্বাদ দেয়াল (Wishes & Photo Guestbook):**
    * মেহমানরা তাদের ছবি এবং মিষ্টি আশীর্বাদবার্তা আপলোড করে পোস্ট করতে পারেন।
12. **হোস্ট অ্যাডমিন ড্যাশবোর্ড (PIN Protected):**
    * পরিবারের সদস্যদের জন্য গোপন পিন প্রোটেক্টেড ড্যাশবোর্ড (ডিফল্ট পিন: `1234`)।
    * মোট কতজন মেহমান আসবেন তার পরিসংখ্যান।
    * মেহমানদের তালিকা এক ক্লিকে **Save as PDF** / প্রিন্ট করার ব্যবস্থা।
13. **হোয়াটসঅ্যাপে নিমন্ত্রণ শেয়ার বোতাম:**
    * আত্মীয়-স্বজনকে সহজে এক ক্লিকেই নিমন্ত্রণপত্রের লিঙ্ক হোয়াটসঅ্যাপে ফরোয়ার্ড করার সুবিধা।

## 🚀 লোকাল মেশিনে রান করার নিয়ম (Run Locally)

```bash
# ডিপেন্ডেন্সি ইন্সটল
npm install

# ডেভেলপমেন্ট সার্ভার চালু
npm run dev
```

ব্রাউজারে `http://localhost:5173` ওপেন করলেই সাইটটি লাইভ দেখতে পাবেন।

## 🌐 সম্পূর্ণ বিনামূল্যে GitHub Pages-এ পাবলিশ করার নিয়ম (Free Deployment)

১. গিট ইনিশিয়ালাইজ করে আপনার GitHub রিপোজিটরিতে কোড পুশ করুন:
```bash
git init
git add .
git commit -m "Initial commit for Hindu Wedding E-Nimontron"
git branch -M main
git remote add origin https://github.com/<your-username>/<repo-name>.git
git push -u origin main
```

২. গিটহাব রিপোজিটরির **Settings** > **Pages** ট্যাবে যান:
   * **Source** অপশনে `GitHub Actions` নির্বাচন করুন।
   * প্রজেক্টে থাকা `.github/workflows/deploy.yml` ফাইলটি স্বয়ংক্রিয়ভাবে সাইটটি বিল্ড করে ফ্রিতে লাইভ করে দেবে!
